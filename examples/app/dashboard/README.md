# Dashboard App Shell

General-purpose multi-page dashboard example (Phase 15 Wave 1).

Build TypeScript:

```bash
bun packages/point/src/cli.ts build-ts examples/app/dashboard/dashboard.point generated/dashboard.ts
```

Check and index:

```bash
bun packages/point/src/cli.ts check examples/app/dashboard/dashboard.point
bun packages/point/src/cli.ts index examples/app/dashboard/dashboard.point
```
