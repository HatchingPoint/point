## Summary

Point Language is available through the VS Code Marketplace for VS Code and Cursor users.

## What it installs

The extension provides editor chrome and starts `point lsp` for language intelligence. The compiler still comes from the `point` CLI on `PATH`.

## Keep editor support portable

The Marketplace extension is not the only supported editor path. Neovim, Zed, and other clients can launch `point lsp` directly.
